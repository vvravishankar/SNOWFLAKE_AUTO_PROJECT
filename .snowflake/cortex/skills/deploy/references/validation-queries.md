# Validation Queries Reference

Quick-reference validation SQL for each deployment step.

## Step 1: RBAC & Infrastructure

```sql
-- Warehouse
SHOW WAREHOUSES LIKE 'AUTOPULSE_WH';

-- Database
SHOW DATABASES LIKE 'AUTOPULSE_AI';

-- Schemas (expect 5: RAW, CLEAN, CURATED, DQ, OPS)
SELECT SCHEMA_NAME
FROM AUTOPULSE_AI.INFORMATION_SCHEMA.SCHEMATA
WHERE SCHEMA_NAME IN ('RAW','CLEAN','CURATED','DQ','OPS')
ORDER BY SCHEMA_NAME;

-- Roles (expect 5)
SHOW ROLES LIKE 'AUTOPULSE_%';

-- Users (expect 3 team + RAVI_SHANKAR)
SHOW USERS LIKE 'PRASHANT%';
SHOW USERS LIKE 'SHAREEN%';
SHOW USERS LIKE 'VEERESH%';
```

## Step 3: RAW Layer

```sql
-- Tables (expect 11 RAW + 1 PIPELINE_RUNS in OPS)
SELECT TABLE_SCHEMA, TABLE_NAME
FROM AUTOPULSE_AI.INFORMATION_SCHEMA.TABLES
WHERE TABLE_SCHEMA IN ('RAW', 'OPS')
  AND TABLE_TYPE = 'BASE TABLE'
ORDER BY TABLE_SCHEMA, TABLE_NAME;

-- Pipes (expect up to 12)
SHOW PIPES IN SCHEMA AUTOPULSE_AI.RAW;

-- Stage
SHOW STAGES IN SCHEMA AUTOPULSE_AI.RAW;

-- File format
SHOW FILE FORMATS IN SCHEMA AUTOPULSE_AI.RAW;
```

## Step 4: CLEAN Layer

```sql
-- Tables (expect 11)
SELECT TABLE_NAME
FROM AUTOPULSE_AI.INFORMATION_SCHEMA.TABLES
WHERE TABLE_SCHEMA = 'CLEAN'
  AND TABLE_TYPE = 'BASE TABLE'
ORDER BY TABLE_NAME;
```

## Step 5: DQ UDF

```sql
-- Function exists
SHOW USER FUNCTIONS LIKE 'NORMALIZE_EVENT_DATE' IN SCHEMA AUTOPULSE_AI.DQ;

-- Quick test
SELECT AUTOPULSE_AI.DQ.NORMALIZE_EVENT_DATE(TO_DATE('0025-06-15')) AS RESULT;
-- Expected: 2025-06-15
```

## Step 6: DQ Procedure

```sql
SHOW PROCEDURES LIKE 'RUN_DQ_FW' IN SCHEMA AUTOPULSE_AI.DQ;
```

## Step 7: DQ Rules

```sql
SELECT COUNT(*) AS RULE_COUNT FROM AUTOPULSE_AI.DQ.DQ_RULES;
SELECT DISTINCT SOURCE_TABLE FROM AUTOPULSE_AI.DQ.DQ_RULES ORDER BY SOURCE_TABLE;
```

## Step 8: DQ Streams + Tasks

```sql
-- Streams (expect 11)
SHOW STREAMS IN SCHEMA AUTOPULSE_AI.DQ;

-- Tasks (expect 11, state = started)
SHOW TASKS IN SCHEMA AUTOPULSE_AI.DQ;

-- DQ tables (expect 3: DQ_RULES, DQ_RESULTS, REJECTED_RECORDS)
SELECT TABLE_NAME
FROM AUTOPULSE_AI.INFORMATION_SCHEMA.TABLES
WHERE TABLE_SCHEMA = 'DQ' AND TABLE_TYPE = 'BASE TABLE'
ORDER BY TABLE_NAME;
```

## Step 9: Curated Dynamic Tables

```sql
-- Dynamic tables (expect 4)
SHOW DYNAMIC TABLES IN SCHEMA AUTOPULSE_AI.CURATED;

-- Check target lag (should be 1/2/3/4 minutes for demo)
SELECT "name", "target_lag", "refresh_mode", "scheduling_state"
FROM TABLE(RESULT_SCAN(LAST_QUERY_ID()));
```

## Step 10: OPS Layer

```sql
-- OPS tables (expect 7: 6 cost + PIPELINE_RUNS)
SELECT TABLE_NAME
FROM AUTOPULSE_AI.INFORMATION_SCHEMA.TABLES
WHERE TABLE_SCHEMA = 'OPS' AND TABLE_TYPE = 'BASE TABLE'
ORDER BY TABLE_NAME;

-- Task (expect 1, state = started)
SHOW TASKS IN SCHEMA AUTOPULSE_AI.OPS;

-- Procedure
SHOW PROCEDURES LIKE 'OPS_COST_REFRESH' IN SCHEMA AUTOPULSE_AI.OPS;
```

## Step 11: Semantic Views

```sql
SHOW SEMANTIC VIEWS IN DATABASE AUTOPULSE_AI;
-- Expect 3: AUTOPULSE_BATTERY_INTELLIGENCE, AUTOPULSE_DQ_INTELLIGENCE, AUTOPULSE_OPS_INTELLIGENCE
```

## Step 12: Cortex Agents

```sql
SHOW AGENTS IN SCHEMA AUTOPULSE_AI.CURATED;
-- Expect 2: AUTOPULSE_BATTERY_AGENT, AUTOPULSE_DQ_INTELLIGENCE

DESC AGENT AUTOPULSE_AI.CURATED.AUTOPULSE_BATTERY_AGENT;
DESC AGENT AUTOPULSE_AI.CURATED.AUTOPULSE_DQ_INTELLIGENCE;
```

## Step 13: Full Summary

```sql
-- All objects by schema
SELECT TABLE_SCHEMA, TABLE_TYPE, COUNT(*) AS CNT
FROM AUTOPULSE_AI.INFORMATION_SCHEMA.TABLES
GROUP BY TABLE_SCHEMA, TABLE_TYPE
ORDER BY TABLE_SCHEMA, TABLE_TYPE;

-- All tasks across database
SHOW TASKS IN DATABASE AUTOPULSE_AI;

-- All dynamic tables
SHOW DYNAMIC TABLES IN DATABASE AUTOPULSE_AI;

-- All semantic views
SHOW SEMANTIC VIEWS IN DATABASE AUTOPULSE_AI;

-- All agents
SHOW AGENTS IN DATABASE AUTOPULSE_AI;
```
