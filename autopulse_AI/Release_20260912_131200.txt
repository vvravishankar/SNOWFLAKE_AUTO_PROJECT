DATA FLOW
----------------------------------------------------------------
CSV Files → @AUTOPULSE_RAW_STAGE
         → Snowpipes → RAW tables (11)
         → DQ Streams detect new rows (11)
         → DQ Tasks call RUN_DQ_FW() (11)
              → DQ_RESULTS (pass/fail stats)
              → REJECTED_RECORDS (quarantine)
              → CLEAN tables (validated rows)
         → Dynamic Tables auto-refresh from CLEAN (4)
              → VEHICLE_BATTERY_360
              → VEHICLE_EVENT_CONTEXT
              → VEHICLE_BATTERY_RCA
              → VEHICLE_BATTERY_PREDICTION
         → Semantic Views expose business metrics (3)
         → Cortex Agents answer questions via Analyst (2)
         → Streamlit Dashboard visualizes everything
